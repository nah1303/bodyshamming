# BODY SAFE AI — Trợ lý AI nhận diện và phòng ngừa hành vi miệt thị ngoại hình

Dự án Nghiên cứu Khoa học Kỹ thuật (KHKT) dành cho học sinh THCS.

## Thông điệp dự án
**Tôn trọng ngoại hình – Bảo vệ cảm xúc – Lan tỏa yêu thương**

## Hướng dẫn chạy ứng dụng
1. **Chạy trực tiếp file web (Nhanh nhất & Dễ nhất):**
   - Mở file `index.html` trực tiếp bằng trình duyệt Google Chrome, Edge hoặc Cốc Cốc.
   - Giao diện Single Page Application (SPA) đã được tích hợp đầy đủ 4 trang và mô phỏng AI hoạt động ngay lập tức mà không cần cài đặt backend.

2. **Chạy theo mô hình Python Flask Backend:**
   - Cài đặt thư viện: `pip install flask`
   - Chạy backend: `python app.py`
   - Truy cập vào: `http://127.0.0.1:5000`
